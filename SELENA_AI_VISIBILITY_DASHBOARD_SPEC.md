## 1. Что за продукт

Selena Systems продаёт **замер AI-видимости**: где бизнес появляется, когда
человек спрашивает у ChatGPT, Gemini или Perplexity совета, кого называют
вместо него и на какие источники ссылаются ответы.

Два канала, которые **никогда не смешиваются в одно число**:

- **Visitor View** — что показывают живому человеку на поверхности. Через
  Bright Data. Тариф $49: 3 поверхности, 25 вопросов, 300 ответов в месяц.
- **API View** — что модель отвечает из собственных знаний, без веб-поиска.
  Через OpenRouter. Часть тарифа $79: оба канала, 8 систем, 800 ответов.

Владелец — Selena, не разработчик, работает голосом, живёт на Бали (UTC+8).

## 4. ЗАДАЧА: перестроить AI Visibility в двухпанельный продукт

### 4.1 Принцип

Левая панель — **постоянный контекст продукта**. Она видна во всех разделах и
отвечает на вопрос «что сейчас анализируется и с чем сравнивается».

Правая панель — **рабочая область** выбранного раздела: таблицы, графики,
ответы AI, доказательства, действия.

```text
┌──────────────────────────┬─────────────────────────────────┐
│ ПОСТОЯННЫЙ КОНТЕКСТ      │ РАБОЧАЯ ОБЛАСТЬ                 │
│ бренд, рынок, конкуренты,│ графики, ответы AI, evidence,   │
│ запросы, системы, задачи │ анализ и выполнение действий    │
└──────────────────────────┴─────────────────────────────────┘
```

### 4.2 Левая панель: структура и источники данных

Ключевое: **почти всё уже есть в серверных функциях**. Не писать заново —
подключить.

```text
SELENA SYSTEMS
[ AI Visibility ▼ ]          ← переключатель продукта

CURRENT BRAND
Selena Systems               ← getSelenaProjectFn / getSelenaWorkspaceFn
selenasystems.com
USA · English

MEASUREMENT
Overview                     ← getSelenaDashboardFn
Visibility                   ← getSelenaGraderReportFn → systems[]
Share of Voice               ← getSelenaGraderReportFn → systems[].shareOfVoice
Query Fan-Out                ← server/query-fanout.ts
AI Answers                   ← getSelenaMeasurementFn, getSelenaRunDetailFn
Citations                    ← getSelenaSourceMapFn

MARKET CONTEXT
Competitors             6    ← getSelenaGraderReportFn → roster[] (isBrand=false)
Commercial Queries     24    ← server/selena-scenarios.ts
Prompt Library         42    ← server/prompts.ts, server/bulk-prompts
AI Systems              8    ← getSelenaGraderReportFn → systems[].length

IMPROVEMENT
Opportunities          12    ← getSelenaRecommendationFindingsFn
Recommendations         9    ← getSelenaRecommendationsFn
Action Plan             5    ← getSelenaActionPlanFn
Evidence Ledger        38    ← server/selena-run-explorer.ts, getSelenaRawEvidenceUrlFn

SETTINGS
Brand Profile                ← confirmSelenaProfileFn, getSelenaProfileSuggestionFn
Markets & Languages          ← svProjects.languages / country / region
Data Sources                 ← server/selena-sources.ts
Team & Access                ← server/team.ts
```

**Правила чисел рядом с пунктами:**

- число = количество объектов в коллекции, не «сколько хорошо»;
- если раздел не настроен — вместо числа состояние («не настроено»), а не `0`.
  Ноль означает «посчитали, там пусто»; отсутствие настройки — другое;
- если данных нет, потому что замер не проводился, — так и писать, не `0`.

### 4.3 Правая панель: что открывается по каждому пункту

| Пункт | Рабочая область |
|---|---|
| Overview | сводка последнего замера: охват, упоминания, стоимость |
| Visibility | разбивка по системам, отдельно branded / category вопросы |
| Share of Voice | доля бренда против конкурентов, только там где охват ≥ 80% |
| Query Fan-Out | как один вопрос разворачивается в подзапросы |
| AI Answers | **таблица «вопрос → на каких системах назвали»** + текст ответа |
| Citations | домены, на которые ссылались ответы, и попал ли туда свой сайт |
| Competitors | список из roster, сколько раз назван, средняя позиция |
| Commercial Queries | вопросы, по которым клиент хочет продавать, с источником набора |
| Prompt Library | все вопросы, версия набора, кто её утвердил |
| AI Systems | какие системы проверяются, в каком канале |
| Opportunities | где не называют нас, но называют сопоставимых |
| Recommendations | что менять, с доказательством из ответов |
| Action Plan | что принято в работу и кем |
| Evidence Ledger | что изменилось между замерами и какой был результат |

**AI Answers — приоритет номер один.** Сейчас этого представления нет вообще, а
именно за него платит клиент. Данные: `sv_runs.mention`, `sv_runs.system_id`,
`sv_scenarios.text`. Тип `GraderQuestion` в `packages/lib/src/selena-grader-report.ts`
сейчас несёт только `{ text, language, branded }` — его надо расширить
результатом по каждой системе.

### 4.4 Поведение

- активный пункт подсвечен, состояние сохраняется при переходах;
- левая панель не перерисовывается при смене раздела;
- на мобильном превращается в drawer;
- переключение продукта (`AI Visibility ▼`) **полностью заменяет** содержимое
  левой панели;
- маршруты: `apps/web/src/routes/_authed/app/` — сейчас там `selena.tsx`,
  `selena-report.tsx`, `selena-order.tsx`, `selena-admin.tsx`, `selena-sources.tsx`.
  Их надо привести к общему layout, а не плодить новые изолированные страницы.

### 4.5 Границы — чего делать не надо

- **Не выгружать в левую панель содержимое коллекций.** 42 вопроса и шесть
  карточек конкурентов слева превращают панель в приборную доску корабля,
  который боятся запускать. Слева — структура, выбор, статусы, количества.
  Подробности справа.
- **Не смешивать с Content Control Room** — это другой продукт.
- **Не показывать долю там, где охват ниже 80%.** Правило уже действует в
  журнале сайта и в отчётах: вместо процента «мало данных» и объяснение.
- **Не усреднять каналы.** Visitor View и API View — разные наблюдения.
- **Не придумывать конкурентов, цифры и цитаты.** Всё показанное должно
  прослеживаться до строки в `sv_runs`.

### 4.6 Приёмка

Готово, когда:

1. человек за минуту понимает, какой бренд анализируется, на каком рынке и с
   кем сравнивается — не открывая ни одного раздела;
2. по каждому пункту левой панели справа открывается работа, а не заглушка;
3. `AI Answers` показывает по каждому из 25 вопросов, на каких системах бренд
   назван, и даёт открыть текст ответа;
4. нигде нет процента, посчитанного по неполной выборке;
5. на телефоне панель складывается в drawer и не мешает работе.

## 5. Очередь после этой задачи

1. **Топ-10 вопросов.** Пересечение трёх признаков: есть реальный спрос по
   Search Console, AI нас не называет, AI называет сопоставимого. Не мнение.
2. **Новый набор вопросов для Chito Bistro** — грузинская кухня, а не
   рестораны вообще. Смена набора начинает новую серию, старая остаётся в
   истории.
3. **Сбор «похожих вопросов»** из ответов Perplexity: `related_prompts`
   приходит в payload и сейчас выбрасывается. Это бесплатное исследование
   настоящих формулировок.
4. **Автоэкспорт отчётов в GitHub** — сервис `measure` после замера кладёт файл
   в репозиторий. Убирает передачу данных скриншотами.
5. **Perplexity: разобраться с потерями** — снимок не успевает за 10 минут.

## 6. Правила работы

**Честность чисел — это продукт, а не стиль.**

- Молчание провайдера никогда не записывается как молчание AI.
- Доля ниже 80% охвата не показывается.
- Чужой бизнес не публикуется без записанного согласия.
- Ничего не выдумывать: имена, цифры, цитаты, интеграции.

**Технически.**

- PR в `release/selena-visibility-mvp`.
- Миграции не запускать без явной просьбы владельца.
- Защиту цепочки поставок pnpm не ослаблять.
- Тесты — на поведение, а не на форму компонентов.
- Коммиты — обычные повелительные предложения, без префиксов.
