# Измерение, отчётность, ROI

Источники: Ahrefs AEO Course (4.1–4.2), Marie Haynes (GSC AI reports), Ilana Gershteyn
(Edmunds, Inside SEO Week), Crawling Mondays ep.3–4, Exposure Ninja.

## Честная рамка ожиданий

- ROI AI-поиска пока никто уверенно не «взломал» (даже enterprise): атрибуционная цепочка
  ранг→клик→конверсия для генеративного поиска мертва. Мысли как в наружной рекламе:
  performance + брендинг. Не обещай точный ROI — обещай систему измерения.
- Ценность без клика реальна: повторяющееся появление бренда в ответах = «билборд».
  Клиент-инсайт: «мы хотим, чтобы бренд видели везде», даже без кликов.
- Невидимая петля: увидел в ChatGPT → загуглил бренд → конверсия записана в organic/direct.
  Тренд (Ahrefs): за год доля direct выросла 37%→41% интернет-трафика, search упала 37%→28%.
- Качество AI-трафика аномально высокое: конверсия 14.2% против 2.8% органики (Loganix);
  у Ahrefs 0.5% визитов из AI = 12.1% регистраций (23x органики). Это главный аргумент
  в отчёте.

## Три измеримых сигнала

1. **AI referral traffic**: клики из ChatGPT/Perplexity/Claude и т.д. Всегда занижен
   (часть ссылок не передаёт referrer). Использовать как направление и относительную
   динамику, не как абсолют. Настройка: GA4 (канал AI-трафика) или Ahrefs Web Analytics.
2. **Активность AI-ботов по страницам**: citation-бот зачастил на страницу = страница
   используется источником в ответах. Логи сервера/CDN; бюджетно — Microsoft Clarity
   (отчёт по AI-ботам: доступы, ошибки, топ-страницы) или Cloudflare-интеграции.
   Смотреть корреляцию «краулят много ↔ появляемся в ответах».
3. **Self-reported attribution** — самый важный: «Как вы о нас узнали?» в форме
   регистрации/чекаута/post-purchase + привычка сейлзов спрашивать «где нашли? что
   спрашивали у ChatGPT?». Только так видна реальная доля AI.

## GSC: отчёт Search Generative AI

- Дает ИМПРЕШНЫ в AIO / AI Mode / Discover AI. Без кликов, позиций и запросов
  (мультимодальные 50-словные запросы с картинками невозможно показать как ключевики;
  заменитель — query groups). Каждый уникальный URL в ответе = отдельный импрешн.
- Рабочий цикл: страницы с AI-импрешнами × обычный performance-отчёт (клики) →
  страницы с высокими импрешнами И кликами = формат, который работает → разбор «почему
  кликают» (глубина? первичный опыт? что есть на странице, чего нет в AI-ответе?) →
  выводы в контент-план.
- Bing Webmaster Tools даёт больше first-party данных (промпты, темы, интенты) — подключай.
- Опция opt-out из AI-фич существует (регуляторика), но для 99% сайтов выключаться из
  AIO = выключиться из поиска. Единственный кейс — крупные медиа на переговорах с Google.

## Метрики для регулярного отчёта

- Share of voice в AI-ответах по core-промптам vs конкуренты, по платформам раздельно.
- Mentions / citations / cited pages, динамика.
- Сентимент и «за что рекомендуют» (key business drivers) — совпадает ли с позиционированием.
- Точность: что AI отвечает о бренде (мониторинг-промпты), инциденты и исправления.
- AI referral трафик и конверсии + брендовый/direct трафик (растёт при AI-видимости).
- Доля «узнали через AI» из self-reported attribution.
- Волатильность — норма: одиночные падения промпта ≠ инцидент; смотреть тренды тем.

## Управление «uh-oh» моментами (просадка после апдейта/смены модели)

- Управляй уверенно: свой POV на причину, чистый анализ, коммуникация на все уровни.
  Данные строят доверие: анализ → тесты → валидация.
- Фронтир-модели меняются без предупреждения — фиксируй смену модели как событие в отчёте.
- Ожидай поток «а ChatGPT сказал нам делать вот так» от руководства — часть работы теперь
  образовательная: рамка ожиданий, объяснение волатильности, план адаптации.
