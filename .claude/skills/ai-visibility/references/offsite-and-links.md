# Упоминания вне сайта, digital PR и ссылки

Источники: Ahrefs AEO Course (3.2–3.3), Exposure Ninja, Brie Moreau (iPullRank Inside SEO Week),
Crawling Mondays ep.5, Marie Haynes.

## Почему это фактор №1

- Исследование Ahrefs (75 000 брендов): branded web mentions — сильнейшая корреляция с
  видимостью в Google AIO, сильнее бэклинков, referring domains и DR.
- Упоминания на страницах с большим ссылочным весом — корреляция 0.70 с попаданием в AIO:
  качество страницы-носителя важно не меньше количества упоминаний.
- AI-ответ — «проблема корроборации»: LLM резюмирует из многих мест. Если о тебе говорит
  только твой сайт — тебя не включат. Консистентность сообщения (сайт, соцсети, PR, форумы,
  пресс-релизы) критична; расхождения = недоверие.
- Упоминание без ссылки тоже ценно; ссылка на третью сторону, говорящую о тебе, даже
  достовернее твоей собственной. «The Guardian занял цитату» = твоё упоминание там — победа.

## Три яруса площадок

1. **Редакционные** (сложнее всего, ценнее всего): отраслевые издания, обзорники
   (Wirecutter/TechRadar-типа), листиклы и сравнения на авторитетных блогах, обзоры
   ютуберов. Это и есть 43.8% цитат ChatGPT.
2. **UGC/комьюнити**: Reddit (один из самых цитируемых источников ChatGPT И базовый корпус
   обучения LLM), Quora, нишевые форумы. Правило: находить треды с вопросами, на которые
   твой продукт/экспертиза честно отвечает, и давать реальные ответы. Спам брендом
   выстрелит в ногу.
3. **Свои площадки**: доп. домены (если сами авторитетны), YouTube-канал, подкаст, LinkedIn —
   всё индексируется и кормит консенсус.

## YouTube — отдельная строка

- Самый цитируемый домен в Google AIO (≈5.6% всех цитат) и в AI Mode (с большим отрывом).
- Корреляция YouTube-упоминаний с видимостью в ChatGPT — 0.737, сильнейший фактор из
  изученных (GPT-4 обучался на 1M+ часов транскриптов — AI не просто цитирует YouTube,
  он на нём УЧИЛСЯ).
- Тактика: «search hits» — вечнозелёные видео под поисковые запросы (стабильный трафик
  из Google+YouTube search и максимальная цитируемость), а не вирусные всплески.
  Поиск тем: Site Explorer по youtube.com/watch → ключевики топ-3 + нишевые термины.
- Чеклист video SEO: ключевик в заголовке и первых строках описания; таймкоды-главы;
  ПРОИЗНОСИ ключевик вслух (Google парсит аудио); удержание внимания.
- Плюс спонсорства и аутрич к обзорщикам в нише.

## Digital PR: новая работа

- Старая работа: ссылки для авторитета. Новая: попадание бренда на КОНКРЕТНЫЕ страницы,
  которые уже цитируются AI в твоей категории.
- Процесс: citations/sources-отчёты (Brand Radar, Semrush) → какие домены и страницы кормят
  ответы по твоим темам → фильтр релевантности (отсечь шум и сайты конкурентов) →
  посмотреть контекст упоминания конкурента → аутрич/контент/данные, чтобы попасть туда же.
- Легче попасть в НОВУЮ статью издания по теме, чем заставить журналиста править старую.
  Лови циклы обновления листиклов.
- Не жди, пока страницу процитируют: страницы с большим ссылочным весом по твоей теме —
  будущие цитаты. Content Explorer: `тема title:best OR title:vs -ТвойБренд` + фильтр по
  referring domains = список листиклов без тебя.
- Wikipedia: цитируется массово; правки жёстко модерируются, но присутствие реально
  (Salesforce ~1000 упоминаний из Wikipedia против 18 у конкурента — это стратегия).
- Reddit-цели: Site Explorer по reddit.com → Organic Keywords → топ-5 позиций + нишевые
  термины = треды, уже ранжирующиеся в Google по твоей теме.
- Инфлюенсеры: тестовые поиски → кто уже упоминает бренд естественно → усиливать их
  (микро-инфлюенсеры с вовлечённой аудиторией > мегаблогеры). Когда тебя упомянули в
  видео/треде — ссылайся, встраивай, взаимодействуй: помогаешь этому контенту ранжироваться
  дальше и работать на тебя.

## Ссылки: что реально работает (Brie Moreau, 300K+ AI-цитат)

- «DR 40+ и трафик сайта 20K+» — мёртвый критерий (с link spam update июля 2021).
- Две бинарные переменные: (1) есть ли у страницы-донора СОБСТВЕННЫЙ трафик (reasonable
  surfer patent — реальные клики по ссылке), (2) ранжируется ли она по целевому или
  смежному запросу = находится ли в кластере cosine-близости (topic-sensitive PageRank:
  у Google фактически «свой бот на каждый ключевик», обходящий ограниченный радиус вокруг
  темы и игнорирующий 99.9% интернета — там и живут бесполезные guest posts).
- Тот же принцип для AI-цитат: ценные цитаты = страницы в топическом кластере с трафиком.
- Гигиена: мониторь упоминания (страницы обновляются, бренд выпадает из листиклов молча);
  дезинформация чинится: сначала свой сайт, потом запрос правок издателю — скорость важна,
  пока AI не выучил ошибку.

## Preferred Sources (Google)

- Теперь для любых сайтов со свежим контентом (не только новостных). Пользователь добавляет
  тебя в предпочитаемые источники → видит тебя в СВОИХ AIO/AI Mode + в карусели по
  развивающимся темам.
- Внедрение: ссылка `google.com/preferences/source?q=твойдомен.com` в конце каждого поста +
  призыв «добавьте нас в предпочитаемые источники». Аудитория бренда = твой личный буст
  видимости.
