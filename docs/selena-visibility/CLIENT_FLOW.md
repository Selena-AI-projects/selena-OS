# Клиентский поток: четыре шага, как у HubSpot

Решение владельца: клиентский кабинет повторяет поток HubSpot AEO дословно,
без изобретательства. Одна страница `/app/selena`, полоса прогресса из четырёх
шагов, ни одно внутреннее понятие (preflight, permit, QC, цикл) на экран не
выходит.

| Шаг | Экран | У HubSpot | Что под капотом |
|---|---|---|---|
| 1 | Бизнес: название, сайт, город, конкуренты | Activate AEO | профиль бренда (есть) |
| 2 | Вопросы: авто-подбор, правка, галочки, «Утвердить» | Prompts | сценарии PROPOSED→APPROVED (есть; утверждение переезжает из админки) |
| 3 | Одна кнопка «Запустить замер» с подтверждением суммы | Grade My Brand | startSelenaMeasurementFn: заказ→одобрение→очередь (есть) |
| 4 | Результаты: упоминания, доля голоса, конкуренты, источники; до готовности — прогресс N/M | Results | стадия анализа ответов (есть) |

Отличие от HubSpot ровно одно и оно намеренное: вопросы утверждает человек
галочками, потому что их автоподбор без проверки — ошибка, которую мы поймали
на их собственном продукте.

Оператору остаётся `/app/selena-admin` для нештатных случаев (остановка,
QC, бюджет). Обычный путь владельца и клиента — эти четыре шага.

Оплата: пока онлайн-платежей нет, шаг 3 доступен только роли admin (владелец
запускает замеры сам). Когда включатся платежи, между шагами 2 и 3 встаёт
оплата — и больше ничего не меняется.
