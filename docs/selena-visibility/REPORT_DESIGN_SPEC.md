# ТЗ владельца: отчёт Snapshot/$49 в дизайне уровня HubSpot AI Search Grader

Сформулировано со слов владельца 24.08.2026, после её прохождения
https://www.hubspot.com/ai-search-grader по «esqobar bali».
Макет для утверждения: артефакт «Отчёт Selena Snapshot» (Claude Artifacts).

## Требование, дословно по смыслу

1. **Вход — три поля, мгновенно.** Название, сайт, локация — и всё.
   Никаких длинных анкет («никаких 150 вопросов»). Отчёт делается быстро
   и показывается сразу, ничего лишнего не спрашивая.
2. **Опциональные поля остаются.** Instagram и ссылка на Google Maps —
   дополнительно, по желанию. Эта работа уже сделана и не выбрасывается.
3. **Дизайн один в один по классу HubSpot-грейдера:** имя бренда крупно,
   строка «по N системам · локация · отрасль», колонки по системам с
   кольцевыми индикаторами, строки метрик с барами и «Смотреть детали»,
   разбивка рынка (донат с долями), список источников, футноты про модели,
   кнопка «Скачать отчёт (PDF)».
4. **Показывать, откуда AI берёт данные** — блок источников с цитированием
   и citation gap («цитируется без вас»). Подаётся как наблюдаемый факт,
   не как механизм.
5. **Вопросы утверждает клиент** — единственный обязательный шаг между
   вводом и отчётом. Это намеренное отличие от HubSpot.
6. **Глубже HubSpot за счёт наших фич:** каждая цифра открывается до
   сырого ответа, хранение ответов 13 месяцев, сравнение циклов,
   Landscape-апсел ($79: +5 API-систем).
7. **Методика — обязательный блок отчёта:** сколько вопросов, сколько
   повторов на вопрос, итоговое число ответов и способ проверки по каждой
   системе — Visitor View (глазами живого посетителя, пользовательский
   сервис) или API View (внутреннее знание модели, без веб-поиска).
   Способ печатается из фактической конфигурации замера (measurementScope
   в lock), никогда из копирайта.
8. **Все вопросы и все конкуренты перечислены поимённо:** полный список
   заданных вопросов и полный список конкурентов из профиля (9–10) плюс
   извлечённые из ответов, по каждому — счётчик упоминаний и позиция
   (НЕИЗВЕСТНО, если не назван).
9. **Таблица «где вас нет»:** по каждому вопросу, где бренд не назван, —
   система, кто показан вместо бренда (топ-2–3), на какие источники
   ответ ссылался, ссылка на полный текст ответа.
10. **Рекомендации входят в тариф $49.** Блок «Что делать дальше»:
    каждая рекомендация выводится из конкретного наблюдения замера
    (источник «без вас», категорийный вопрос без бренда, слабое
    цитирование своего сайта) и ссылается на эту цифру. Без обещаний
    попадания в ответы; Expert Verified ($399) добавляет проверку
    рекомендаций человеком.

## Обязательные правила честности (не обсуждаются, из CABINET_MODEL)

- Никакого композитного «общего балла /100» — брендовые и категорийные
  вопросы всегда раздельно. Это второе намеренное отличие от HubSpot.
- Пустая группа = НЕИЗВЕСТНО, не 0%.
- Доли и позиции — только наблюдаемые из ответов; имена конкурентов —
  только реально извлечённые из замера.
- В макете все цифры помечены «пример»; реальный отчёт берёт данные
  только из выполненного замера.

## Решение владельца по тарифам (24.08, вторая итерация)

- **$49 и $79 — один экран отчёта**, различие данными, не дизайном:
  Snapshot $49 = 3 системы Visitor View, 24 ответа; Landscape $79 =
  те же секции + таблица «API View» на 5 моделей (64 ответа) + секция
  «Динамика по циклам» (в первом цикле — НЕИЗВЕСТНО, сравнение
  появляется со второго).
- **$399 Expert Verified**: подтверждено «проверяет человек», состав
  того, «что даётся человеком», владелец решит позже — в отчёте пока
  только строка про ×5 повторов и проверку человеком, без деталей.
- В макете тарифы переключаются табами Snapshot/Landscape в шапке.

## Куда строить

Отчёт — это существующая стадия анализа (`selena-answer-analysis`,
`computeOrderAnalysis`) + ledger-отчёт кабинета, пересобранные в один
экран по макету. PDF — отдельным шагом после утверждения экрана.

## Решение владельца: месячный запас ответов (24.08, третья итерация)

- $49 и $79 — подписка с месячным запасом: до 100 вопросов × 3 системы =
  **300 ответов/мес** ($49) и до 100 × 8 = **800 ответов/мес** ($79).
  Формула считается из каталога (`monthlyAnswerAllowance`), не из копирайта.
- Клиент сам решает, как тратить запас: хоть 50–100 вопросов одним замером,
  хоть еженедельными прогонами — пока сумма ответов месяца в пределах запаса.
- Заказ сверх остатка честно отказывает с цифрами
  (SELENA_MONTHLY_ALLOWANCE_EXCEEDED); использование месяца видно в шапке
  отчёта: «использовано N из 300».
- Ответ себестоимости: ~$0.005 API-ответ, ~$0.01 Visitor-ответ (оценки из
  usage/cost.ts, сверяются с реальными счетами); потолки заказов $12/$28/$48
  остаются жёсткой границей.
