# Находки — заголовки, 2026-09-28 (публичная версия)

Только заголовки и влияние. Воспроизведение, точные эндпоинты неисправленных уязвимостей,
внутренние идентификаторы и доказательства — в приватном комплекте (`Aether-Medium`, см. `README.md`).
Приоритеты по ТЗ 8.10.

## P0 — остановить вред
- **Контроль доступа в Aether (×2).** Возможны действия с чужими объектами между проектами.
  Изоляция на уровне ролей/API в остальном держится.
- **Переток данных при переотзыве привязки.** После отзыва привязки Aether-проекта другой
  арендатор, привязав тот же проект, может получить в Inbox чужой входящий черновик.
- **Aether RLS без политик.** Изоляция арендаторов держится только в коде; БД её не подстраховывает.
- **Аварийный стоп vs бесплатная проверка (AI Visibility).** При включённом стопе бесплатная
  проверка резервирует бюджет и вызывает провайдера.

## P1 — замкнуть цепочку
- **Шлюз не подписывает манифест** на всех развёрнутых коммитах (с 3 сентября) — доставка
  невозможна. С однострочной правкой в песочнице цепочка доходит до публикации.
- **Production Control Room не подключён** — события идут в staging-приёмник; у боевого web нет
  своего домена.
- **Обратного канала нет** ни в одну сторону: статус, одобрение, метрики не возвращаются в Aether.
- **`task.result.ready` не проецируется** в Inbox (расходится с документацией).
- **Отказ `NOT_SENT` отвергается БД** → после починки шлюза станет ложным «доставлено».
- **Метрики не подключены** → раздел Performance пуст.
- **Тупик одобрения в Aether** — автор не может одобрять, участников проектов нет → большинство
  задач в production одобрить некому.
- **Aether развёрнут из неслитой ветки; свежая сборка фронта падает** — расхождение кода и деплоя.
- **Оператор AI Visibility не видит заявки других организаций.**
- **Права роли AI Visibility ломаются при чистой установке** (условные GRANT не воспроизводятся).

## P2 — гигиена
- Наблюдаемость: шлюз/проекция/приёмник в production не пишут прикладных логов; инцидент без
  причины; нет инструмента досылки dead-letter.
- Телеметрия по умолчанию уходит в проект вышестоящего Elmo, если не задан `DISABLE_TELEMETRY`.
- Неподключённые части: Trigger.dev (нет деплоя задачи), Postiz (нельзя выбрать).
- Мобильная вёрстка Aether Studio (390 px) переполняется.
- `/api/local-ready` всегда «ok»; `www.selenasystems.com/check` изредка падает на первой загрузке.
- Документация: `START_HERE.md` только в неслитых ветках; COVERAGE.md обещает несуществующую
  проекцию; устаревшая карта экосистемы.
- Railway-гигиена: лишние копии Postgres и тома, app.* в окружении «staging», две копии STRAND.
